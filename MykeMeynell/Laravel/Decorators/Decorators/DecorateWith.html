DecorateWith

Since: 1.0.0

final class DecorateWith implements MethodDecorator

Delegates decoration behavior to an arbitrary callable.

This attribute allows ad-hoc decoration without creating a dedicated attribute class. Targets can be global functions, static methods, instance methods resolved via the container, or invokable classes.
